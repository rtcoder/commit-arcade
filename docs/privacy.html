Privacy

GitHub profile DOM in, local game out, nothing uploaded.

  • No account credentials are collected.
  • No contribution data is uploaded.
  • No browsing history is collected.
  • No telemetry is enabled by default.
  • No external analytics are included.
  • Gameplay preferences and high scores remain local in browser storage.

Commit Arcade uses a content script only on https://github.com/*. It does not request broad extension permissions or host permissions.
