Commit Arcade

Play your GitHub contributions.

Commit Arcade turns the visible contribution graph on a GitHub profile page into a tiny local arcade screen. It runs only on github.com, uses packaged extension code, and restores the graph when play stops.

v1.0 Release

Chrome and Chromium

Use the Chrome package for Chrome, Edge, Brave, Opera and Vivaldi. Store submission assets are prepared under docs/store/chrome.

Firefox

Use the Firefox package and AMO source archive from the v1.0 release workflow. Reviewer notes are ready in QA docs.

Safari

Safari remains an Xcode packaging path for v1.0. See extension/safari/README.md for the manual conversion flow.

Games

Commit Arcade ships fourteen playable games: Commit Runner, Snake, Flappy Commit, Pong, Breakout, Space Invaders, Tron, Frogger, Helicopter, Commit Beat, Missile Command, Centipede, Mini Tetris and Asteroids.

View controls and troubleshooting.

Privacy And Review

No credentials, contribution data, browsing history, analytics or telemetry are collected or transmitted. Gameplay preferences and high scores remain local in browser storage.

Read the privacy statement or review CHANGELOG.md.
