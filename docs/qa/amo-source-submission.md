# Firefox AMO Source Submission

Commit Arcade's Firefox package is built from TypeScript with esbuild. If AMO requests source review material, submit
the source archive generated by:

```sh
npm ci
npm run build:firefox
npm run validate:firefox
npm run package:firefox -- v1.0.0
npm run package:amo-source -- v1.0.0
```

Expected artifacts:

- `dist/commit-arcade-firefox-v1.0.0.zip`
- `dist/commit-arcade-firefox-source-v1.0.0.zip`

AMO listing metadata and reviewer notes are prepared in `docs/qa/firefox-amo-listing.md`.

Reviewer environment:

- Node.js 22.x
- npm 10.x or newer
- macOS, Linux or Windows shell capable of running `npm` scripts

The source archive includes `package.json`, `package-lock.json`, build scripts, manifests, shared TypeScript source,
CSS, assets, tests and QA documentation. It excludes generated extension build directories, `dist/`, `node_modules`,
local IDE metadata and git metadata.

Reproducibility notes:

- `npm ci` installs dependencies from `package-lock.json`.
- `npm run build:firefox` creates `extension/firefox/build`.
- `npm run package:firefox -- v1.0.0` writes the installable AMO upload archive.
- Store archives intentionally exclude source maps; the submitted source archive contains the TypeScript sources used to
  build the bundled content script.
